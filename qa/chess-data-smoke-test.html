Chess Data Smoke Test

This browser-run checker replays every opening and variation from the standard starting position, then applies each puzzle's solution and checks its declared goal. It does not evaluate whether a move is strategically best.

Run this through a local web server from the project root (for example, python -m http.server 8000), then open /qa/chess-data-smoke-test.html. Internet is required to load chess.js from its CDN.
